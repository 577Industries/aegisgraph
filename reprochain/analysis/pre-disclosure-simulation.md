# Pre-Disclosure Simulation

The simulation question is narrow: given public target source anchors and a library-level parser risk model, would AegisGraph have elevated the media decode path as a validation task before disclosure?

Acceptable output:

- scored reachability records
- explicit limitations
- source anchors and derived measurements
- validation tasks for fuzzing or harness work

Unacceptable output:

- raw exploit inputs
- live target interaction
- claims that static analysis alone proves a target vulnerability
- disclosure-sensitive reproducer material in public exports
