# Research Safety Policy

This repository supports defensive, academic, and professional research for DARPA ASEMA.

Hard boundaries:

- no live-target probing or production-account interaction
- no credentialed testing without written authorization
- no raw crash payload publication
- no undisclosed maintained-library findings in public exportable records
- no target source redistribution
- no claims that static analysis alone proves a live vulnerability

The validator enforces these boundaries for evidence records and generated exports preserve the public/private split.
